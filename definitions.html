<> langage

=> faculté humaine de produire et de comprendre un énoncé

=> depend du contexte (ton,..)

=> infinité de contenus

=> possibilité de dire une même chose de plein de manière différentes (plusieurs langues,..)

=> possibilité d'étudier le langage

=> découplage entre ce que l'on dit et ce qui existe

=> pas neutre

=> s'éxprime toujours dans une langue

=> il a toujours plus à comprendre que ce qui est dit explicitement (sous entendus,..)

=> ensemble de règle sur lequel nous avons la possibilité de critiquer

=> intrument de communication

=> expression des idées

=> passe par la representation

=> semble être determiant pour le developpement du langage

=> forcement public (Wittgeinstein)

<> langue

=> systeme dans lequel le langage s'exprime

=> composé de signes avec deux faces (signifiant(son, image ..)/signifié (idée, notion ..) avec un lien contigent entre eux (Saussure)
